Motor y memoria

Al pulsar Levantar, la app prepara automáticamente los archivos del motor si faltan. El proceso consume RAM; la base conserva sus datos en disco al detenerlo.

La opción compatible con SQL Server utiliza Babelfish sobre PostgreSQL (WiltonDB). Permite usar el driver JDBC de Microsoft, pero no ejecuta el motor Microsoft SQL Server.

La compatibilidad T-SQL es parcial. No admite archivos MDF ni copias BAK.

Detener SQLLIGHT

Esto detendrá todas las bases de SQL Server gestionadas por la instancia SQLLIGHT. Las aplicaciones conectadas perderán su conexión.

Recuperar entornos

Los motores portables, incluido TDS experimental, conservan sus datos y credenciales cifradas al eliminarlos. Las bases de una instancia Microsoft SQL Server heredada se borran permanentemente.

Instalar SQL Light

Se instalará un servicio con inicio automático, un acceso en Inicio y el icono junto al reloj. Los entornos y los datos actuales se conservan en esta carpeta.

Los entornos que ahora estén activos se volverán a levantar desde el servicio. Sus conexiones se interrumpirán brevemente durante el cambio. Después puedes elegir Levantar al iniciar por entorno.

Windows pedirá permisos de administrador. El servicio utiliza una cuenta de Windows con permisos limitados. Desinstalar retira el servicio y los accesos, conservando los datos.

Conexiones del servidor

Sesiones visibles en la base, excluyendo esta consulta de monitorización. Las conexiones en espera pueden pertenecer al pool JDBC. Hikari gestiona su propio límite dentro de la app Java.
